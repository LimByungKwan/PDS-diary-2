# 검사 구분

- 현재 앱 현재 검사: `node tests/auth-card1.mjs`. 실제 Better Auth/Drizzle 어댑터와 독립 SQLite로 가입·로그인·중복 가입·익명 401·양방향 소유권 404·세션 취소·만료·가져오기를 검사한다.
- 보안 패턴 검사: `python3 tests/security-audit.py`. 실제 비밀값을 출력하지 않는다. 패턴 검사만으로 완전한 보안을 주장하지 않는다.
- `verify.mjs`, `results.json`, `contract-results.json`은 기준 원본에서 이어받은 기준 기록이다. 현재 앱은 로그인 없는 초기화와 공용 데이터 접근을 제거했으므로 옛 기준 원본 검사 파일을 그대로 현재 앱 통과 검사로 사용하지 않는다.
- 모든 자동 검사 자료는 임시 DB에만 저장한다. 사용자의 실제 일기·실제 5일 기록을 생성하지 않는다.

현재 앱 공부 관찰: `node tests/study.mjs`는 격리된 SQLite에 합성 시각 5일을 사용해 시작 기준·규칙 변경 순서·계정 경계·중복·결측·집계를 확인합니다. 실제 5일 기록은 만들지 않습니다. 인증 통합 검사에는 `/api/study`의 비로그인 차단·계정 위조 무시·내보내기 소유권도 포함됩니다.
